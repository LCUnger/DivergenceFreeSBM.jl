## Notes

### 1. Questions about the study material

**SBM: Remark 1 and the boundary map**

- Luuk asked whether Lipschitz regularity of the true boundary guarantees a unique, smooth closest-point projection, as suggested in Remark 1 of Main and Scovazzi (`main2018shifted`).
- The supervisors explained that the grid should resolve the features of the true boundary: those features should not be smaller than the characteristic mesh size $h$.
- They also explained that the method needs a suitable map from the surrogate boundary to the true boundary; uniqueness of the closest-point map is not essential for constructing a map. Finding such a map is a separate computational problem.

**SBM: Where is $\bar{u}(\tilde{\mathbf{x}})$ defined?**

- Luuk asked about the domain of $\bar{u}(\tilde{\mathbf{x}})$.
- The supervisors explained that it is defined on the surrogate boundary $\tilde{\Gamma}$ and carries the Dirichlet data from the true boundary $\Gamma$ to $\tilde{\Gamma}$. In other words, it supplies the prescribed boundary value associated with each surrogate-boundary point.

**SBM: Discretization error and the stabilization terms in equation (16)**

- Luuk asked what error the stabilization terms introduce when the solution is approximated in a discrete space, given that the formulation is consistent for the exact solution.
- The supervisors' answer was that the introduced error is of the same order as the discretization error.

**Gridap.jl: Integral notation in the weak form**

- Alexandru Porumbiţă asked how to enter integral symbols when writing a weak form in Gridap.jl.
- Julia supports Unicode characters. The recommended VS Code extension was **Fast Unicode Math Characters**, which converts LaTeX-style input into Unicode characters.
